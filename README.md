# Palindrome Checker

## Description

This Java program checks whether a given number is a palindrome.

## Steps

1. Enter a number.
2. Store the original number.
3. Reverse the number.
4. Compare the original and reversed numbers.
5. If both are equal, the number is a palindrome.
6. Otherwise, it is not a palindrome.

## Example

**Input:** `121`

**Output:** `Palindrome`

## Requirements

* Java JDK
* Java IDE or text editor
